# my-own-travel-plan

以地圖探索渡假村、景點與旅遊文章的峴港／會安旅遊規劃網站。

## GitHub Pages

此專案使用 `.github/workflows/static.yml`，會在推送到 `main` 後部署整個 repository 根目錄。因此網站入口檔是根目錄的 `index.html`，並搭配 `styles.css` 與 `app.js`；不需要放進 `docs/`。

## 這一版可以做什麼

- 在互動地圖上比較渡假村與周邊景點
- 了解每個渡假村／景點的推薦重點與適合的旅行方式
- 直接開啟官方介紹、旅遊文章與 Google Maps
- 收藏候選地點；清單保存在目前瀏覽器的本機儲存空間
